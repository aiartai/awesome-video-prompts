“Hurry back! …Naruto!!”

Style: hyper-realistic cinematic, IMAX, anamorphic lens, shallow depth of field, volumetric dust, smooth camera motion with slight handheld realism, no glow effects, no stylized anime shading, no text overlays, 16:9
